Politique de confidentialité

Résumé

  • Mes Apps EPS est un portail qui regroupe des outils pour l’enseignant d’EPS. Il fonctionne sans compte, sans serveur de données et hors ligne.
  • La liste d’élèves importée depuis Pronote (fichier .csv) est enregistrée uniquement sur votre appareil, dans la base locale du navigateur (IndexedDB).
  • Seules cinq informations sont conservées : nom, prénom, date de naissance, classe et régime. Les autres colonnes du fichier Pronote (adresse e-mail, sexe, tuteur, options…) sont ignorées à l’import.
  • Aucun cookie, aucun outil de mesure d’audience, aucune publicité, aucun service tiers de suivi.
  • Hébergement des fichiers de l’application (code uniquement, sans donnée d’élève) sur GitHub Pages : github.com/VinzToc/Mes_Apps_EPS.

Dernière mise à jour : octobre 2026.

1. Cadre RGPD

Mes Apps EPS est une application gratuite qui permet aux enseignants d’EPS de regrouper leurs outils pédagogiques et de partager entre eux une liste d’élèves unique. Dès qu’un enseignant importe une liste d’élèves, il manipule des données à caractère personnel au sens du RGPD.

  • Finalité — fournir une liste d’élèves commune aux applications pédagogiques (appel, évaluation, suivi, association sportive…) et la consulter par classe.
  • Minimisation — seuls les champs utiles sont conservés (nom, prénom, date de naissance, classe, régime). Le régime (externe, demi-pensionnaire, interne) est utile à l’organisation de certaines activités ; ne l’importez pas si vous n’en avez pas l’usage.
  • Sans compte — aucune identification en ligne n’est nécessaire pour utiliser l’application.
  • Copies locales — les données présentes uniquement sur votre appareil ne peuvent pas être supprimées à distance. Vous gardez la main via l’export, le bouton « Effacer toutes les données » ou la désinstallation.

3. Où elles restent

  • Navigateur — sur Windows, iPhone/iPad, Android et Mac, les données sont stockées dans l’IndexedDB du navigateur (ou de l’application installée), propre à cet appareil et à ce navigateur. Les applications du catalogue hébergées sous le même domaine partagent cette base ; aucune autre origine n’y a accès.
  • Fichiers d’export — le fichier liste_eleves_EPS.csv que vous exportez et enregistrez où vous le souhaitez (cloud personnel, clé USB, messagerie…) relève de votre responsabilité une fois exporté.

4. Supprimer ou exporter

  • Exporter — onglet « Élèves », bouton « Exporter CSV complet » : liste d’origine et colonnes ajoutées par les applications.
  • Supprimer — onglet « Élèves », bouton « Effacer toutes les données » (définitif). Vider les données du site dans le navigateur supprime aussi tout ; les données ne peuvent alors être récupérées que par l’import d’un nouvel export Pronote ou d’une sauvegarde.

5. Conservation des données

Les données restent sur votre appareil tant que vous ne les supprimez pas, tant que le navigateur les conserve ou tant que l’application installée n’est pas désinstallée. Il est recommandé d’effacer la liste à la fin de l’année scolaire ou lorsqu’elle n’est plus utile.

6. Applications du catalogue

Mes Apps EPS fournit des liens vers d’autres applications. Chacune est décrite par sa propre politique de confidentialité. Les applications hébergées sur le même domaine peuvent lire et compléter la liste commune sur votre appareil, sans transmission à un serveur. Aucun élément du catalogue ne reçoit de donnée d’élève par le simple affichage du portail.

7. Hébergement

Les fichiers de l’application (code, images, catalogue) sont servis par GitHub Pages. Comme pour tout site web, l’hébergeur peut traiter l’adresse IP des appareils qui téléchargent ces fichiers (journaux techniques). Aucune donnée d’élève n’est présente sur le dépôt ni transmise à l’hébergeur. Une fois installée, l’application fonctionne hors ligne.

8. Vos responsabilités et bonnes pratiques

En tant qu’enseignant utilisateur, vous restez responsable du traitement des données de vos élèves :

  • Informer votre établissement et vos élèves selon le cadre de votre établissement.
  • Ne pas laisser l’appareil de cours accessible sans verrouillage.
  • Exporter régulièrement une sauvegarde et sécuriser les fichiers exportés.
  • Ne pas publier ou stocker les fichiers de sauvegarde sur un cloud ne respectant pas les règles RGPD.
